华为技术领域资源与课程

11 个方向 · 华为 ICT 学院公开文档与在线课程 · 附资料简介、主要内容与适学基础

按「芯片 → 硬件使能 → 操作系统 → 数据库 → 编程语言 → 应用 → 通信/存储」排列。选方向时先看「适学基础」一栏： 大一建议先走鸿蒙、CodeArts、数据通信这三条零基础可上手的线；芯片与 CANN 方向留到大二有项目需要时再进入。 所有链接均指向华为官方公开页面，注册华为账号后即可免费学习。

芯片01

Ascend 昇腾

华为自研的 AI 处理器与全栈 AI 计算平台，覆盖芯片、板卡、框架到工具链，是国内 AI 算力的主流底座之一。

主要内容：Atlas 训练/推理硬件、昇腾软件栈与算子库、模型迁移适配、推理服务部署。
适学基础：有 Python 基础、了解神经网络基本概念；建议大一下学期后再深入，纯零基础先补深度学习入门。
开发者文档 ↗ 在线课程 ↗
芯片02

Kunpeng 鲲鹏

基于 ARM 架构的服务器与终端处理器及配套生态，是国产化算力平台的核心硬件。

主要内容：鲲鹏处理器与 TaiShan 整机规格、软件迁移与编译适配、性能调优、鲲鹏开发套件。
适学基础：会 Linux 基本命令、有 C/C++ 或计算机组成基础更顺；大一可先看架构与生态概念，动手留到大二。
开发者文档 ↗
硬件使能03

CANN 异构计算架构

昇腾芯片之上的计算架构层，承担算子、图编译与运行时，作用相当于昇腾生态里的「CUDA」。

主要内容：算子开发与 Ascend C 编程、图编译与执行、模型推理加速、算子性能调优。
适学基础：需 C++、并行计算与深度学习基础，难度偏高；建议大二后结合具体项目或竞赛再学。
开源代码仓 ↗ 在线课程 ↗ 课程（ICT 学院）↗
操作系统04

HarmonyOS 鸿蒙

面向全场景的分布式操作系统，一次开发、多端部署，覆盖手机、平板、穿戴、车机与智能家居。

主要内容：ArkTS 语言与 ArkUI 声明式界面、Stage 应用模型、分布式能力、NearLink 星闪 SDK。
适学基础：零基础可入门，会 JavaScript/TypeScript 上手更快；大一非常适合作为第一个完整 App 练手。
开发文档 ↗ NearLink SDK ↗ 在线课程 ↗
操作系统05

openEuler 开源操作系统

开源 Linux 服务器发行版，是国产服务器与鲲鹏生态的主流操作系统底座。

主要内容：安装与日常运维、Shell 与 systemd、内核与驱动、容器与云原生基础。
适学基础：有一点 Linux 命令行基础最好；可与《操作系统》课程同步学，大一先练命令与装系统。
官方文档 ↗ 在线课程 ↗
数据库06

openGauss 关系型数据库

开源关系型数据库，华为 GaussDB 的内核来源，国产数据库方向的入门主线。

主要内容：SQL 与存储过程、安装部署与参数配置、备份恢复、性能调优、主备高可用。
适学基础：需先会 SQL 与数据库基本概念；大一可先自学 SQL，等学过《数据库原理》再深入。
官方文档 ↗ 在线课程 ↗
编程语言07

仓颉 Cangjie

华为自研的静态强类型编程语言，面向全场景智能应用，主打原生并发与跨语言互操作。

主要内容：语法与类型系统、并发模型、与 ArkTS/Java 互操作、包管理与工具链。
适学基础：已有 C / Java / Python 任一基础者最合适；零基础不建议从它起步，先打好一门主流语言。
语言文档 ↗ 在线课程 ↗
应用08

华为云码道 CodeArts

华为云一站式软件开发生产线（DevOps），把需求、代码、构建、测试、部署串成一条流水线，含 AI 辅助编程。

主要内容：项目与代码托管、CI/CD 流水线、代码检查与安全扫描、AI 生成与补全代码。
适学基础：零基础即可上手，适合课程设计、团队项目里练工程协作与版本管理。
产品介绍 ↗ 在线课程 ↗
通信09

数据通信、网络安全

华为 ICT 学院的数据通信与网络安全方向课程，是网络工程的入门主线，可衔接 HCIA 认证路线。

主要内容：TCP/IP 与路由交换、网络协议分析、安全基础与防火墙、常见攻防意识。
适学基础：零基础可学，大一即可开始；与《计算机网络》课程同步效果最好。
数通课程 ↗ 安全课程 ↗ 该方向仅提供课程，无公开文档
通信10

存储

华为存储方向课程，覆盖企业级存储与数据保护，可衔接 HCIA-Storage 认证路线。

主要内容：RAID 与磁盘基础、SAN/NAS 组网、分布式存储、备份与容灾。
适学基础：零基础可学，有一点网络基础更顺；大一以了解概念为主，不必急于考证。
在线课程 ↗ 该方向仅提供课程，无公开文档
通信11

无线、光

华为无线接入与光传输方向课程，面向 5G 网络与光通信，偏通信工程与电子信息方向。

主要内容：5G 网络架构与无线接入、OTN/WDM 光传输、站点与链路基础。
适学基础：零基础可学，适合对通信、电子方向感兴趣的同学；配合《信号与系统》等课程理解更快。
在线课程 ↗ 该方向仅提供课程，无公开文档
